# 🌴 東南アジア＆インド・チル＆ポップBGMコンポーザー (SEA & India Chill Beats Composer)

**東南アジア＆インド伝統楽器（ガムラン・シタール・バンスリ・木琴・一弦琴）× 現代ローファイ・チルビート** ── 勉強・作業・YouTube配信向けBGMジェネレーター

東南アジア（インドネシア、タイ、ベトナム、フィリピン）およびインドの若者層やグローバルリスナーに圧倒的な需要がある「勉強・作業用ローファイBGM（Study with Me）」や「インド古典ローファイ」「インディアン・ジャズ・フュージョン」「ラーガ・フォーカス音楽」「熱帯・モンスーン瞑想アンビエント」を自在に生成できるWebツールです。

---

## 🌐 公開ページ（GitHub Pages）

- **公開URL**: [https://ohapee.github.io/sea-chill-composer/](https://ohapee.github.io/sea-chill-composer/)
- スマートフォン（iPhone / Android）およびパソコンのモダンブラウザでそのまま動作します。
- インストール不要・完全無料・PWA（Progressive Web App）対応。ホーム画面に追加してネイティブアプリ感覚で利用できます。

## ✨ 主な特徴とこだわり

### 1. 東南アジア＆インドYouTube市場に特化したジャンル
1. **SEA Lofi / Chill Beats (最推奨)**:
   - 勉強・作業・プログラミング用。抑制されたBPM 70〜88のブームバップドラムに、温かいローズピアノと東南アジアの伝統民族楽器が優しく溶け合う。
2. **Soulful Indian Classical LoFi (インド古典ローファイ)**:
   - シタール、バンスリ（竹笛）、タンプーラの神聖なドローン、雨の環境音、メロウなローファイビートを融合したリラクゼーション・勉強用BGM。
3. **Indian Jazz Fusion (インディアン・ジャズ・フュージョン)**:
   - 「PickBeat Fusion」のように、タブラのリズム、サックス、バンスリ、エレピが即興的に絡み合うミニマルで知的なDeep Work / Studyセッション。
4. **Raag-Inspired Focus (ラーガ・フォーカス音楽)**:
   - Raag Yaman（夕暮れの安らぎ・集中）、Raag Bilawal（朝の明晰さ）などの古典ラーガ旋律を現代の集中BGMとして再構築。
5. **Carnatic Instrumental / Meditation (南インド古典・ヨガ・スパ)**:
   - サラスヴァティ・ヴィーナ、ムリダンガムによるヨガ・スパ・瞑想用の格調高いアンビエント。
6. **SEA Pop Instrumental Covers**:
   - I-Pop（インドネシア）、T-Pop（タイ）、V-Pop（ベトナム）、OPM（フィリピン）のSpotifyヒットチャートを意識した、切なくエモーショナルな旋律をアコギやピアノで奏でるインスト。
7. **Royalty-Free SEA Music Library**:
   - バリやプーケットの旅行Vlog、カフェ紹介、日常動画に最適な、爽快で前向きなトロピカルハウス＆エスニックビート。
8. **Asian Ambient / Sleep & Meditation**:
   - 不眠解消、睡眠、ヨガ、スパ、瞑想に特化。熱帯スコール（雨音）、竹風鈴、寺院の鐘が深い癒やしを届ける。

### 2. 国別・伝統民族楽器のワンクリック調合
- **🇮🇳 インド**: シタール（Sitar共鳴弦）、バンスリ（Bansuri竹笛）、タブラ（Tabla太鼓）、サロッド（Sarod）、タンプーラ（Tanpuraドローン）、サラスヴァティ・ヴィーナ（Veena）、ムリダンガム（Mridangam）
- **🇮🇩 インドネシア**: ガムラン（Gamelan青銅琴）、サリン（Saron鉄琴）、アンクルン（竹の揺れ音）、ササンドゥ（ヤシ葉ハープ）
- **🇹🇭 タイ**: ラナート・エーク（Ranat木琴）、チャケー（撥弦ツィター）、ソー・ドゥアン（胡弓）、コーン・ウォン（円形ゴング）
- **🇻🇳 ベトナム**: ダン・バウ（Dan Bau一弦琴の幻想的ビブラート）、ダン・ tranh（16弦琴）、クロン・プット（竹琴）、サオ・チュック（竹笛）
- **🇵🇭 フィリピン**: クリンタン（Kulintangゴングチャイム）、クビン（竹製口琴）、トンガトン（竹筒スタンプ）

### 3. 熱帯・モンスーンの環境音・自然音レイヤー
- インドのモンスーン豪雨、ガンジス河の夜明け、バリ島の熱帯スコール（雨音）、メコン川のせせらぎ、バンコクやハノイの深夜オープンカフェ、熱帯雨林の虫の音、寺院の竹風鈴をブレンド可能。

### 4. YouTube動画制作支援機能（90分〜2時間動画対応）
- 東南アジア・インドの学生層に最も刺さる「90分〜2時間の勉強用BGM動画」に最適化された、**英語タイトル（SEO対応）、チャプタータイムスタンプ付き概要欄、ハッシュタグ**を自動生成しワンクリックコピー可能。

### 5. Web Audio API によるリアルタイム・ガムラン＆シタール試聴
- ブラウザ上の内蔵シンセサイザーで、**「バリ島ペロッグ音階（Pelog）ガムラン」×「ラーガ・シタール演奏」×「タブラ/ローファイビート」×「温かいエレピ」×「雨音アンビエント」**をリアルタイム合成演奏。
- 16ステップのバンブーLEDインジケーターがリズムに合わせて点灯します。

### 6. 禁止事項（作業・瞑想の妨害要素を完全除外）
- 先行ツール（ゆるかわBGMコンポーザー等）と同様に、**作業や瞑想の妨げとなる不要な激しい音を完全にシャットアウト**できます。
- 「人の歌声・話し声・ラップ」「激しいEDMドロップ・過剰な重低音」「耳障りな金切ノイズ・歪みギター」「早すぎるテンポ・緊張感・ホラー展開」「けたたましいクラクションやサイレン」などをワンクリックで除外指定可能。
- AI音楽生成ツールの「Negative Prompt / Exclude Styles」欄にそのまま貼り付けられる除外指示テキストも自動生成・ワンクリックコピーできます。

### 7. PWA完全対応 & 主要AI音楽モデル最適化
- **Suno / Udio**: スタイル指定タグと構成指示を自動出力。
- **Google Flow Music**: 音響設計と楽器バランスを緻密に指定。
- **PWA対応**: Service Workerと専用マニフェストにより、AndroidやiPhoneのホーム画面にネイティブアプリとしてインストール可能。

## 📱 スマートフォンでのご利用方法

1. ブラウザ（SafariまたはChrome）で公開URLを開きます。
2. **Androidの場合**:
   - ヘッダーに表示される**「📲 アプリをインストール」**ボタンをタップします。
   - または右上のメニューから「アプリをインストール」を選択します。
3. **iPhone (Safari) の場合**:
   - 画面下の共有ボタン（四角形から上向き矢印）をタップし、**「ホーム画面に追加」**を選択します。
4. ホーム画面にエメラルドアイコンが追加され、全画面アプリとして起動できます。

## 💻 ローカル環境での起動方法

パソコンのターミナルから直接動かす場合は、作業ディレクトリ（`/home/eiichi/src/sea_chill_composer`）にて以下を実行してください。

```bash
# パソコン上で開く場合（自動でブラウザが立ち上がります）
./run_server.sh

# 自宅Wi-Fi経由でスマホから直接開く場合（ターミナルにQRコードが表示されます）
./run_mobile.sh
```
